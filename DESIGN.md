# Quota views

Mode: Operate. Reference: the user-supplied October 28 screenshot; it is visual
evidence, not a source of account data or network configuration.

Ledger uses the existing warm paper/charcoal tokens and typography. Its primary
layout is identity / weekly / five-hour / Fable / actions, with thin horizontal
rules, quiet provider summaries and teal remaining-capacity bars. The default
view is Ledger; Cards is an intact alternative. Remember the choice locally.

Avoid an extra page heading, hero counters or duplicate account panels in Ledger.
On narrow widths, preserve readable identity/actions and wrap the three labeled
meters below, without shrinking the desktop table into illegibility. The timeline
retains its existing horizontal scroll and date/zoom controls.

No fake full meters, fabricated reset dates or invented aggregate token budgets.
Provider summaries show only the provider and credential count; no aggregate Fable total.
Sort by reported subscription, highest first (Ultra > Max > Pro), with stable ties.
Claude Max 20x API observations are labeled Ultra; Max 5x is labeled Max.
A persistent Hide emails switch masks identities in Ledger, Cards, timeline and
quota action messages with a blurred placeholder and a brief shimmer. Reduced
motion keeps the static mask. Never put a hidden address in text or tooltips.
Retain safe confirmation for banked reset grants. Expose refresh, errors, stale
observations, unknown Fable allowances and all additional quota data.

Confirmed uncapped Ultra sessions retain their column with an infinity symbol,
a dashed neutral track and "No 5-hour cap / Weekly limits still apply". Never
render an unbounded session as a full percentage bar; absent/failed data is unknown.
Reset selection uses the shared confirmation modal, native radio choices and the
existing palette. Each grant exposes type, remaining count, exact expiry and a
relative countdown. No default grant selection; unavailable grants stay visible.

The Ledger details disclosure opens beside its own ellipsis trigger, with an
8px gap. Flip above when necessary, constrain it to viewport margins, and track
scroll/resize. Keep it above floating page chrome but below confirmation modals.
Escape closes and restores trigger focus; outside interaction closes it.
